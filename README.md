# Alumni Management System (Java)

A Java-based system to manage and maintain records of former students, converted from a Python project to utilize Object-Oriented Programming (OOP) principles.

## 🚀 Features
- **Register Alumni:** Add new student details with specific sessions.
- **View Details:** Display formatted records of all registered alumni.
- **Search & Delete:** Quickly find or remove records from the system.

## 🛠️ Technical Implementation
- **Language:** Java
- **Data Structures:** Uses `ArrayList` for dynamic storage.
- **Concepts:** Classes, Constructors, and Encapsulation.

## 💻 How to Run
1. Open your terminal in the project folder.
2. Compile: `javac AlumniManager.java Alumni.java`
3. Run: `java AlumniManager`
